# 💰 Paisa Pro — Smart Money Tracker

A beautiful personal finance tracker to manage your daily expenses and earnings.

---

## 🚀 How to Use (Just 1 Step!)

### Double-click `Paisa Pro.bat`

That's it! The app will open in your browser automatically.

> **Keep the black terminal window open** while using the app.
> Close it when you're done.

---

## 📱 Features
- ✅ Track daily expenses & earnings
- ✅ Multiple payment modes (Cash, UPI, Card, etc.)
- ✅ Budget limits & alerts
- ✅ Beautiful charts & analytics
- ✅ Dark mode
- ✅ Auto-save data in browser
- ✅ Export/Import data as JSON backup
- ✅ Safety Vault snapshots (data recovery)
- ✅ Recurring transactions

---

## 💾 Your Data is Safe!
Data is auto-saved in your browser. For extra safety:
- Go to **Settings → Export Data** to download a JSON backup
- Go to **Settings → Hard Drive Auto-Save** to save directly to a file

---

## ❓ Troubleshooting

**App not opening?**
- Make sure the black terminal window is still open
- Try going to `http://localhost:5180/` manually in Chrome

**Blank page?**
- Close the terminal, double-click `Paisa Pro.bat` again
